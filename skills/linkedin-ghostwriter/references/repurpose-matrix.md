# Matrice de Recyclage & Découpage Multi-Posts (Repurpose Matrix)

> **La Règle d'Or du Recyclage** : Un résumé d'article ou de vidéo n'intéresse personne. Ne faites **JAMAIS** de résumé. Extrayez les pépites qui ont la force de vivre comme une publication indépendante et autonome.

---

## ⛏️ Les 6 Pépites à Extraire d'un Document Long

À partir d'un README GitHub, d'une vidéo YouTube, d'un post-mortem d'incident ou de notes de réunion, scannez le document pour extraire :

| Pépite à Rechercher | Ce que c'est concrètement | Exemple |
| :--- | :--- | :--- |
| **1. Les Affirmations Tranchées** | Toute phrase qui déclencherait un débat passionné entre experts | *"Les tests end-to-end ralentissent les équipes sans améliorer la qualité."* |
| **2. Les Chiffres Révélateurs** | Chaque métrique, durée, coût en euros, pourcentage de gain | *"-40% de temps de build, 14 000 € économisés, 0.4s de latence."* |
| **3. Les Moments de Crise** | Une scène précise avec un échec, une panique et un coût humain | *"Le serveur s'est éteint 10 minutes avant la démo avec le client."* |
| **4. Les Mécanismes Clés** | L'explication concrète du *"Comment ça fonctionne réellement sous le capot"* | Les 3 étapes de configuration des en-têtes TLS. |
| **5. Les Aveux d'Erreurs** | Une mauvaise décision prise au départ et rectifiée plus tard | *"On a cru que notre problème venait de l'IP alors que c'était l'User-Agent."* |
| **6. Les Phrases Citables** | Une formule courte, mémorable, qui sonne comme un axiome | *"La meilleure ligne de code est celle que vous n'avez pas besoin d'écrire."* |
